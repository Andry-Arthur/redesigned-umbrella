# Andry Rakotonjanabelo Portfolio

This repository contains a personal portfolio site for Andry A. Rakotonjanabelo, built with the Next.js App Router. It presents a concise profile page with a hero section, an about summary, a featured award, selected projects, and social links.

## What’s in the site

- A hero section with name, role, education, location, and contact links.
- An about section focused on AI/ML, accessibility, and hackathon projects.
- A featured awards section highlighting MLH Top 50 2025.
- A selected projects section with links to Devpost, GitHub, and YouTube.
- A footer with LinkedIn, GitHub, and YouTube profiles.

## Tech Stack

- Next.js 16 with the App Router
- React 19
- ESLint for linting
- Plain CSS in app/globals.css for the visual design

## Project Structure

- app/page.js: main portfolio content and sections
- app/layout.js: root layout and metadata
- app/globals.css: global styling and page layout
- public/: static assets used by the site

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open the local site in your browser at the address shown by Next.js.

## Production Build

Create a production build and run it locally:

```bash
npm run build
npm run start
```

## Scripts

- npm run dev: start the development server
- npm run build: create a production build
- npm run start: serve the production build
- npm run lint: run ESLint
